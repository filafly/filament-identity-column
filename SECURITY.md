# Security Policy

## Supported versions

| Version | Supported |
| ------- | --------- |
| 1.x     | ✅ security fixes |
| < 1.0   | ❌ |

Security fixes go into the latest 1.x release. Please update to it before reporting.

## Reporting a vulnerability

Please **don't open a public issue** for a security problem. Email **nolan@filafly.com** with:

- the package (`filafly/filament-identity-column`) and version,
- what an attacker can do, and the steps to reproduce it.

You'll get a reply within 3 working days. Once a fix is released, we'll credit you in the changelog unless you'd rather stay anonymous.
